# Learn JavaScript - Batch 2X

A comprehensive learning repository for JavaScript fundamentals and concepts.

## 📚 Repository Structure

### Chapter 1: JavaScript Basics
Location: `chapter_01_Basics/`

- **01_Bascics.js** - Introduction to JavaScript basics
- **02_JS.js** - JavaScript fundamentals
- **03_JS_Commands.js** - Common JavaScript commands
- **04_HotCode.js** - Hot code examples and patterns

### Chapter 2: JavaScript Concepts
Location: `chapter_02_Javascript_Concepts/`

- **05_JS_Basics.js** - Deep dive into JavaScript basics

### Chapter 3: Identifiers, Literals & Comments
Location: `chapter_03_Indentifier_Literals/`

- **06_Identifier_Rules.js** - Rules and guidelines for identifiers
- **07_Identifier_Part2.js** - Advanced identifier concepts
- **08_Comments.js** - Commenting best practices
- **js_identifier_rules.js** - Identifier rules reference
- **README.md** - Chapter-specific documentation
- **VS_Code_keyboard_shortcut_windows.md** - VS Code shortcuts for Windows
- **VS_Code_keyboard_shortcut_mac.md** - VS Code shortcuts for macOS

## 🎯 Learning Objectives

This repository covers:
- Core JavaScript fundamentals
- Variables and data types
- Identifiers and naming conventions
- Literals and their types
- Comments and code documentation
- JavaScript syntax and commands

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/AbhishekBisht24/LEARNPLAYWRIGHTBATCH2X.git
```

2. Navigate to the repository:
```bash
cd LEARNPLAYWRIGHTBATCH2X
```

3. Open files in your preferred code editor (VS Code recommended)

4. Follow the chapters in order:
   - Start with `chapter_01_Basics/`
   - Progress to `chapter_02_Javascript_Concepts/`
   - Continue to `chapter_03_Indentifier_Literals/`

## 💡 Tips

- Open the JavaScript files in VS Code
- Refer to the keyboard shortcut guides for efficient navigation:
  - Windows: Check `chapter_03_Indentifier_Literals/VS_Code_keyboard_shortcut_windows.md`
  - macOS: Check `chapter_03_Indentifier_Literals/VS_Code_keyboard_shortcut_mac.md`
