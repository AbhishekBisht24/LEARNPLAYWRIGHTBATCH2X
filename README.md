## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/AbhishekBisht24/LEARNPLAYWRIGHTBATCH2X.git
```

2. Navigate to the repository:
```bash
cd LEARNPLAYWRIGHTBATCH2X
```

3. Open files in your preferred code editor (VS Code recommended)

4. Follow the chapters in order:
   - Start with `chapter_01_Basics/`
   - Progress through `chapter_02_Javascript_Concepts/`
   - Continue to `chapter_03_Indentifier_Literals/`

   - Explore `chapter_08_Switch_Statement/`

   - Master arrays in `chapter_11_Arrays/`
   - Dive deep into functions in `chapter_12_Funtions/`
   - Master strings in `chapter_13_Strings/`
   - Explore objects in `chapter_14_Objects/`
   - Master 2D arrays in `chapter_15_2D_Array/`
