# Chapter 26: TypeScript

This chapter introduces TypeScript, a strongly typed superset of JavaScript that helps build safer and more maintainable applications.

## 📚 Overview

TypeScript adds static typing to JavaScript and improves developer productivity through better tooling and error checking.

## 🧠 Key Concepts

### 1. Type Annotations
TypeScript allows you to define variable types explicitly.

```ts
let name: string = "Playwright";
```

### 2. Compile-Time Checking
TypeScript catches errors before runtime.

```ts
let age: number = 25;
```

## 💡 Notes

- TypeScript files use the `.ts` extension.
- You can compile TypeScript to JavaScript using the TypeScript compiler.
- Type annotations make code easier to understand and maintain.
